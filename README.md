# thunders-email-assets

Assets estáticos públicos usados como imagens embutidas (`<img src>`) no
relatório de publicação do Thunders Gestão, servidos via
`raw.githubusercontent.com` para serem alcançáveis pelo proxy de imagens
do Outlook (que não consegue acessar `localhost` nem hosts privados).

Repositório intencionalmente público e sem lógica — só os PNGs.
